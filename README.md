# Webtech Project

## Introduction

This project will be updated weekly with new features in order to have a complete web application using Next.js as a framework.

## Prerequisites

-  Install git
-  Install node.js
    - https://nodejs.org/en/download/package-manager
-  Install Next.js
    - https://nextjs.org/docs/getting-started/installation

## How to use it ?

1. Create a folder
    ```mkdir *folder name*
2. Go to this folder
    ```cd *folder name*
3. Clone the repository to this folder
   ```git clone https://github.com/Vincent23032003/fall2024-webtech-102.git
4. Install the dependencies needed
   ```npm install
5. Run the application with Next.js
   ```npm run dev
