# Webtech Project

## Introduction

This is frontend part of the project. In this part you can find all web pages that composed the website. It will be updated weekly.

## Prerequisites

-  Install git
-  Install node.js
    - https://nodejs.org/en/download/package-manager
-  Install Next.js
    - https://nextjs.org/docs/getting-started/installation

## How to use it ?

1. Create a client folder
    ```bash
    mkdir client
2. Go to this folder
    ```bash
    cd client
3. Run the application with Next.js
   ```bash
   npm run dev
4. Open your localhost on a web browser
    ```bash
    http://localhost:3000
