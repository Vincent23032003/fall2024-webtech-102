# Webtech Project

## Introduction

This is frontend part of the project. In this part you can find all web pages that composed the website. It will be updated weekly.

## Features

### 1. User authentication
- Secure registration and login.
- User session management.

### 2. Content Management
- Display team news and events.
- Publication of articles by administrators.

### 3. Community interaction
- Comment on articles.
- Interaction with other fans via forums or discussions.

### 4. Navigation and accessibility
- Intuitive navigation thanks to a clear menu bar.
- Site optimized for different devices and easy access.

### 5. Profile customization
- Users can personalize their profiles.
- Add a profile photo and edit personal information.


## Technologies used
- Frontend framework**: [Next.js](https://nextjs.org/)
- Language**: TypeScript (tsx)
- Styles**: Tailwind CSS
